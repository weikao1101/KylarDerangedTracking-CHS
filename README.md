# KylarDerangedTracking-CHS

《Degrees of Lewdity》自製模組 KylarDerangedTracking 的簡體中文版本。

## 安裝方式

1. 下載本倉庫中的 `KylarDerangedTracking-CHS.mod.zip`
2. 透過遊戲的 Mod Loader 載入該 zip 檔即可

## 注意事項

- 本模組需先下載遊戲本體《Degrees of Lewdity》才能使用。
- 本模組為簡體中文版本,僅適配 [ModI18N-0.5.11.9-chs-1.0.0a.mod.zip](https://github.com/Eltirosto/Degrees-of-Lewdity-Chinese-Localization/releases/download/v0.5.11.9-chs-1.0.0a/ModI18N-0.5.11.9-chs-1.0.0a.mod.zip),請先安裝該漢化模組。
- 目前相容的遊戲版本為 0.5.11。

## 內容物

- `KylarDerangedTracking-CHS.mod.zip`:打包好的模組檔案,可直接安裝

## 說明

本模組為凱拉爾(Kylar)角色追加病態值追蹤、每日衰退機制、跟蹤觸發、主動接近事件等自製內容。
