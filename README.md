# KylarDerangedTracking

《Degrees of Lewdity》自製模組 KylarDerangedTracking，本倉庫同時提供繁體中文版與簡體中文版。目前版本：v2.0.26。

## 請先確認要下載哪一個版本

| 檔案 | 語言版本 | 適配的漢化模組 |
|---|---|---|
| `KylarDerangedTracking.mod.zip` | 繁體中文版 | 繁體中文漢化模組（ModI18N-cht） |
| `KylarDerangedTracking-CHS.mod.zip` | 簡體中文版 | [ModI18N-0.5.11.9-chs-1.0.0a.mod.zip](https://github.com/Eltirosto/Degrees-of-Lewdity-Chinese-Localization/releases/download/v0.5.11.9-chs-1.0.0a/ModI18N-0.5.11.9-chs-1.0.0a.mod.zip) |

兩個版本不能混用：

- 繁體中文版**不適配**簡體中文漢化模組（ModI18N-chs），請改用簡體中文版。
- 簡體中文版不適配繁體中文漢化模組。
- 搭配錯誤的漢化模組時，部分功能會無法生效，新增的劇情文字也會繁簡混雜。

## 安裝方式

1. 依上表下載對應版本的 `.mod.zip`。
2. 透過遊戲的 Mod Loader 載入該 zip 檔即可。

## 注意事項

- 本模組需先下載遊戲本體《Degrees of Lewdity》才能使用。
- 請先安裝對應語言的漢化模組，再載入本模組。
- 目前相容的遊戲版本為 0.5.11。

## 內容物

- `KylarDerangedTracking.mod.zip`：繁體中文版，打包好的模組檔案，可直接安裝。
- `KylarDerangedTracking-CHS.mod.zip`：簡體中文版，打包好的模組檔案，可直接安裝。

## 說明

本模組為凱拉爾（Kylar）角色追加病態值追蹤、每日衰退機制、跟蹤觸發、主動接近事件等自製內容。
